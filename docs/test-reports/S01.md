Ngày thực hiện: 19/11/2026. Build local `sprint-3.1` trên worktree từ `d1d3787`; chưa commit/push bản mới. Content `sprint-3.1`, save/schema `1`, release cap `5`, design cap `50`.

**Kết quả:** tính năng nền đã tích hợp và kiểm thử local bằng PostgreSQL/SMTP thật. **Chưa đạt cổng staging public** vì chưa có tài khoản/biến môi trường Render, Neon, Resend và domain email. CI có cấu hình nhưng chưa chạy trên GitHub.

## Đã thực hiện

- Content generator + validator: ba class, 18 skill thiết kế, 10 dải map liên tục, asset ID có thật; build chỉ cho skill/cấp tới 5. Dữ liệu sai phải bị từ chối. Công thức XP/điểm đối chiếu 50 dòng progression CSV.
- VI mặc định trên browser `en-US`, đổi EN, lưu preference theo tài khoản và mở từ context khác. Key và placeholder VI/EN khớp.
- Better Auth email/password: đăng ký, gửi xác minh qua SMTP Mailpit, cấm login trước verify, reset mật khẩu, thu hồi session cũ và sign out.
- Tạo/list/chọn ba ô nhân vật với row lock chống tạo đồng thời quá ba; ownership HTTP/WS; không có API nhận snapshot/vàng/XP tùy ý từ client.
- PostgreSQL transaction, revision, journal action ID. Gây lỗi sau UPDATE xác nhận rollback. Hai phiên cùng nhân vật chuyển writer và tải state từ DB.
- Migrate DB trống và chạy lại migration trên DB có dữ liệu. Thư viện vẫn đủ 244 FX và mở chi tiết được.
